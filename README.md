# Banking Site

## 📝 Overview

**Banking Site** is a simple front-end web application built using **HTML**, **CSS**, and **JavaScript** that simulates basic banking operations such as checking account balance, making deposits, and withdrawing funds. This app is designed to showcase basic front-end functionality and can be used as a foundation for more complex banking applications.

The site operates entirely on the client-side, meaning no server-side or database integration is used. It provides a user-friendly experience for simulating a basic banking interface.



## 🚀 Features

- **Responsive Design**: The app is designed to be fully responsive for both desktop and mobile devices.
- **Minimalist UI**: A clean, easy-to-use interface with a focus on essential banking actions.

## 🛠️ Technologies Used

- **HTML**: The structure and content of the banking site.
- **CSS**: Styling for a clean and responsive design.
- **JavaScript**: For handling the logic behind deposits, withdrawals, and balance updates.
